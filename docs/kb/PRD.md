# PRD — 팀 설문

> **이 문서는 초안입니다.** 4교시에 만든 PRD 원본이 이 컴퓨터에 없어서, 지금 코드(`server.py`, `static/*.html`)가 실제로 하는 일을 거꾸로 정리했습니다. 원본이 있으면 이 파일을 원본으로 바꾸고, 차이가 나는 부분은 [결정-기록.md](결정-기록.md)에 남겨 주세요.

## 한 줄 요약
진행자가 자기 노트북 한 대로 띄워서, 같은 와이파이에 있는 팀원에게 **익명 설문**을 받고 바로 결과를 보여주는 도구.

## 누가 쓰나
| 사람 | 하는 일 | 쓰는 화면 |
|---|---|---|
| **진행자(관리자)** | 설문을 만들고, 응답을 받고, 마감하고, 결과를 내려받음 | `/admin.html`, `/admin_edit.html` (이 노트북에서만) |
| **응답자** | 받은 주소로 들어가 한 번 응답 | `/survey.html?code=` |
| **누구나** | 진행 중인 설문 목록과 결과 보기 | `/`, `/result.html?code=` |

## 꼭 지켜야 하는 것
1. **설치 없이 실행**: `python3 server.py` 한 줄. 외부 패키지와 DB 서버 없음.
2. **익명**: 응답자가 누군지 저장하지 않음. 이름, IP, 쿠키 값 모두. 로그에도 IP 없음.
3. **관리는 진행자 노트북에서만**: 다른 기기, 터널, 프록시를 거친 요청은 관리 기능을 못 씀.
4. **한 사람 한 번**: 같은 브라우저에서는 한 설문에 한 번만 응답.

## 기능

### 설문 만들기·고치기 (진행자)
- 제목(200자), 안내 문구(2,000자), 문항 최대 100개
- 문항 타입 7가지: 단답, 장문, 점수(1~5 / 1~10), 하나 고르기, 여러 개 고르기, 예/아니오, 날짜
- 문항마다 필수 여부를 정하고, 고르기 문항에는 "기타(직접 입력)"를 켤 수 있음
- 문항 순서 바꾸기, 삭제
- **응답이 들어온 설문은 문항을 못 바꿈**(제목·안내만). 바꾸려면 "복사해서 새 설문"

### 설문 운영 (진행자)
- 새로 만든 설문과 복사본은 **마감 상태**로 시작하고, "응답 받기"를 눌러야 열림
- 응답 주소와 결과 주소를 복사해서 공유. 와이파이 공유 시 노트북 IP 주소로 보여줌
- 마감, 다시 열기, 응답 초기화, 삭제(되돌릴 수 없음을 확인창으로 알림)

### 응답하기 (응답자)
- 필수 항목, 값 형식, 기타 내용을 서버에서 검사하고 첫 번째 문제를 문장으로 알려줌
- 제출하면 감사 화면과 결과 보기 링크
- 마감됐거나 이미 응답했으면 응답 대신 안내와 결과 링크

### 결과 보기 (누구나)
- 응답 수, 응답 받는 중/마감 표시
- 점수: 점수별 막대와 평균 / 고르기·예아니오: 선택지별 막대와 비율(여러 개 고르기는 응답자 수 대비) / 날짜: 날짜별 개수 / 기타 의견 목록 / 주관식: 무작위 순서 목록
- 자동 새로 고침: 10초마다, 탭을 보고 있을 때만, 응답 수가 바뀌었을 때만 다시 그림
- "CSV 다운로드 (엑셀용)": 응답마다 한 줄인 CSV(엑셀에서 한글이 안 깨지게 BOM 포함, 수식으로 실행되지 않게 처리)

### AI 도우미 (2026-11-06 추가, 선택)
- 진행자가 관리 화면에서 OpenRouter API 키를 넣으면 켜짐
- 응답자: 설문 아래에 하고 싶은 말을 쓰면 AI가 문항에 맞춰 답을 채워 줌. 확인 후 직접 제출
- 결과 보는 사람: 결과 아래에서 "가장 많은 불만은?"처럼 물으면 AI가 결과를 바탕으로 답함
- 화면에 "OpenRouter로 보내진다"고 알림. AI 답은 참고용
