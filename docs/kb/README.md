## 이 kb를 쓰는 규칙

- **작업이 끝나면** [log.md](log.md) 맨 아래에 한 줄을 추가합니다.
- **무언가를 정하면** [결정-기록.md](결정-기록.md)에 이유와 함께 적습니다. 결정을 뒤집을 때는 지우지 말고 "바뀜"으로 표시합니다.
- **API를 바꾸면** [API.md](API.md)와 `tests/`를 같이 고칩니다. 테스트가 API 모양을 고정하고 있습니다.
- **새 자료**(회의록, 요구사항, 캡처 등)는 먼저 [raw/](raw/)에 원본 그대로 넣고, 정리한 내용을 해당 문서에 반영합니다. raw의 파일은 고치지 않습니다.
